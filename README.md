# ReqFlow – AI-Powered Requirements Management System

## Overview
ReqFlow is an AI-powered platform that helps teams write better software requirements.  
It analyzes requirements for clarity, detects missing information, and automatically suggests Acceptance Criteria and Test Cases.

## Problem Statement
Poorly written or ambiguous requirements are one of the major reasons for software project delays and failures.  
Most teams still use basic tools that do not provide intelligent analysis or suggestions.  
ReqFlow solves this by using AI to improve the quality of requirements.

## Features
- Create and manage software requirements
- AI-powered analysis of requirements
- Automatic suggestion of Acceptance Criteria
- Automatic suggestion of Test Cases
- Priority and Status tracking
- Clean and simple user interface

## Tech Stack
- **Backend:** FastAPI, SQLAlchemy, Pydantic
- **Frontend:** Streamlit
- **Database:** SQLite
- **AI:** OpenAI (with Demo Mode support)
